# Strava Fitness Data Analytics

## Project Overview

This project analyzes Fitbit smart-device fitness data to understand user activity, sedentary behaviour, calorie expenditure, sleep patterns, and hourly fitness behaviour.

The project uses Python, SQL, SQLite, and Streamlit to create an interactive data analytics dashboard.

## Objectives

- Clean and preprocess fitness tracker data
- Store cleaned data in SQLite
- Perform SQL-based fitness analysis
- Analyze daily activity patterns
- Analyze sleep behaviour
- Analyze calorie expenditure
- Analyze hourly activity
- Generate insights and recommendations
- Build an interactive Streamlit dashboard

## Technologies Used
